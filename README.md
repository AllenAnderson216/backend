# 缘来是你 · 婚恋交友网站原型

一个漂亮的静态/半交互婚恋网站原型，包含：

- 首页（Hero + 数据亮点 + 功能介绍 + 精选会员）
- 优质会员列表 + 多条件筛选（性别 / 城市 / 年龄）
- 智能匹配界面（类似 Tinder 的左右滑动）
- 个人主页展示
- 会员详情弹窗

## 如何运行

直接用浏览器打开 `index.html` 即可，无需服务器。

或者使用本地静态服务器：

```bash
# 如果有 Python
python -m http.server 8080

# 然后访问 http://localhost:8080
```

## 技术栈

- 纯前端：HTML + Tailwind CSS（CDN）+ 原生 JavaScript
- 图标：Font Awesome
- 无后端，数据为前端模拟

## 功能说明

| 页面     | 功能说明 |
|----------|----------|
| 首页     | 品牌展示、数据、精选会员预览 |
| 优质会员 | 卡片列表 + 性别/城市/年龄筛选 |
| 智能匹配 | 滑动卡片，左右选择，随机匹配成功弹窗 |
| 我的主页 | 个人资料完整展示示例 |
